Understand Anything

Interactive codebase knowledge graphs · 9 specialized skills · Phase 0→7 pipeline

What it is — A family of skills that turn any codebase into a navigable knowledge graph. Open-source upstream (Leigest519 lineage) integrated into Hermes.

How it uses Hermes hub — Phase 1-3 call CodeGraph for file/edge enumeration instead of parsing from scratch. Phase 4-7 stores graph in .ua/ directory, surfaced via Brain Bridge wiki_search.

Usage Flow

1
Pick a skill — understand for full graph, -chat for Q&A, -diff for PR review
2
Pass a path or query as argument
3
Understand Anything walks Phase 0→7, calling CodeGraph for code structure + Brain Bridge for related notes
4
Output: knowledge graph file, dashboard URL, or interactive Q&A session

Examples

# Full graph of a repo
/understand ~/my-project

# Ask about it
/understand-chat "What does this project do?"

# PR diff analysis
/understand-diff feature-branch

# Single file deep-dive
/understand-explain src/auth/login.py

# Business domain extraction
/understand-domain --full

# Launch interactive dashboard
/understand-dashboard ~/my-project

# New agent onboarding
/understand-onboard ~/my-project

Integrate with CodeGraph

The skills read from .ua/ directories — when codegraph is initialized on the same repo, file structure is pre-indexed so phase 1-2 complete much faster.

# In your project
codegraph init .
# then
/understand .
