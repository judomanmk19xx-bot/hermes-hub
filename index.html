Understand Anything - integrated

Generates interactive codebase knowledge graphs (Phase 0-7)

How it uses the Hermes hub:

  1. Phase 1-3 uses CodeGraph to enumerate files + relationships instead of parsing from scratch
  2. Phase 4-7 stores summary graph in `.ua/` directory; surface frontmatter readable via Brain Bridge wiki_search
  3. Outputs `knowledge-graph.json` that Hermes can navigate via Unified Memory

Replicate the system

Stand up these subsystems in order. Each is independent - you can stop at any layer.

1
1. Install Hermes Agent: `hermes setup`
2
2. Install CodeGraph: `brew tap obot-platform/tap && brew install codegraph`
3
3. Index your codebase: `codegraph init `
4
4. Install Brain Bridge: `pip install hermes-brain-bridge`
5
5. Index your notes: configure `wiki_paths` in Brain Bridge env
6
6. Optional: stand up Mnemosyne for vector memory
7
7. Optional: install Understand Anything for graph-style onboarding

One-liner install

# Install the agent + graph core
brew tap obot-platform/tap && brew install codegraph
pip install hermes-agent hermes-brain-bridge

# Index your codebase
codegraph init /path/to/your/repo

# Start the brain bridge with your notes path
hermes-brain-bridge --wiki ~/my-wiki --port 9111

CodeGraph quick reference

# Stats
codegraph status ~/your-repo

# What calls this function?
codegraph callers "my_function"

# What does this function call?
codegraph callees "my_function"

# If I change this, what's affected?
codegraph impact "my_function"

# File tree
codegraph files --path . --max-depth 3 --format tree

# Wire into your agent
codegraph install   # prompts for agent choice
